# 互关检测助手 · 存档版

免费的 Chrome 侧栏扩展。导入 X 官方数据存档，在本机按账号 ID 比对两张名单。

| 名单 | 含义 |
| --- | --- |
| 对方未回关 | 存档里你关注了对方，对方没有关注你 |
| 我未回关 | 存档里对方关注了你，你没有关注对方 |

## 安装与使用

1. 在 [Releases](https://github.com/Awak3n1ngOne/x-follow-check/releases/latest) 下载并解压 `X-Follow-Check-Archive.zip`。
2. 在 Chrome 120 或更新版本打开 `chrome://extensions`，开启开发者模式，选择「加载未打包的扩展程序」。选择包含 `manifest.json` 的目录。
3. 在 X 的「设置和隐私 → 你的账号 → 下载你的数据存档」申请导出，下载后解压。[X 官方下载说明](https://help.x.com/zh-cn/managing-your-account/accessing-your-x-data)
4. 打开 Chrome 工具栏里的扩展。点击「导入存档文件夹」并选择解压后的 `data` 文件夹，也可以用「选取文件」同时选择同一份存档里的 `follower.js`、`following.js` 及其分卷。
5. 点击顶部的名单切换方向。搜索支持账号 ID，以及存档提供的名称和用户名。点击一行可打开对应的 X 资料页，在 X 中手动关注或取关。

很多存档只包含账号 ID。列表会原样显示 ID，便于按账号打开资料页。结果反映导出时的关系，重新导出并导入即可更新。

## 浏览器缓存

版本只读取用户选中的关注与粉丝文件。比对后的两张名单、人数及导入时间保存在当前 Chrome 配置的本地扩展存储中。重启浏览器或重新打开侧栏时会自动加载缓存。侧栏底部可以清除缓存。

扩展使用侧栏和本地存储权限。文件解析、比对和搜索均在本机完成。打开资料页或帮助链接时，浏览器按所选链接打开 X。

## 开发

直接以未打包扩展加载仓库目录即可，无需构建。

运行解析与比对测试：

```sh
node --test
```
